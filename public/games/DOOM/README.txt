DOOM (1993), SHAREWARE EPISODE
==============================

What's here
- doom.wasm: id Software's DOOM engine (the source id released under the GNU GPL v2),
  built for web browsers by Cornelius Diekmann in his "WebAssembly from Scratch" project:
  https://github.com/diekmann/wasm-fizzbuzz/tree/gh-pages/doom  (source code of this build)
  Taken from the wasm-doom npm package (https://github.com/iam-medvedev/wasm-doom), unchanged.
- Inside it: the shareware DOOM data file (doom1.wad, version 1.9, unmodified,
  MD5 f0cefca49926d00903cf57551d901abe). The shareware episode "Knee-Deep in the Dead"
  is the part of DOOM that id Software let anyone copy and share for free.
- index.html and cover.svg: made for ROKI.

DOOM is a trademark of id Software. ROKI isn't connected to id Software.

Controls: arrows move, Ctrl fires, Space opens doors, Shift runs, Alt + arrows strafes,
1-7 pick weapons, Enter picks in menus, Esc opens the menu. Phones get on-screen buttons.
There's no sound in this build.
